# 델파이 설문지 검토 및 개선 사항

참고 파일(`.hwp`)의 표 이미지 5개에서 **27개 세부 구성요소를 원문 그대로** 옮겨
`survey/items.tex` 에 정리했습니다. 원본 표는 이미지에서 옮겨 적은 것이므로,
각 표의 마지막 행이 잘리지 않았는지 원본과 한 번 대조해 주세요.

## 1. 형식·구조 개선

| 원본 | 개선 | 이유 |
|---|---|---|
| 중분류 모듈이 별도 열 → 표가 7열로 복잡 | 중분류를 표 안의 **구분 행**으로 변경 | 열 수 감소, 세부 구성요소 설명 공간 확보 |
| 목차 번호 `II.` 중복 (작성 방법 / 평가) | I. 응답자 정보 → II. 작성 방법 → III. 평가 → IV. 중요도 → V. 종합 의견 | 번호 오류 수정 |
| 안내문은 "적절함" 척도, 표 머리는 "그렇다" 척도 | 표 머리도 **전혀 부적절 ~ 매우 적절**로 통일 | 척도 표현 불일치는 응답 오류·타당도 문제의 원인 |
| 의견은 영역 하단에만 | 문항별 **수정·보완 의견** 칸 추가 + 영역별 의견란을 추가/수정/삭제로 구조화 | 문항 수정안을 정확히 수집 |
| — | 영역마다 **영역 전체 구성 타당성**(D1~D5) 문항 | 중분류 체계 자체의 타당성 검증 |
| — | 인사말, 연구 참여 동의, IRB 번호, 회신 기한 | 윤리 심의·학위논문 심사 요건 |
| — | **응답자 일반 정보** (전문 분야, 단위, 경력, VR 경험) | 논문에 전문가 패널 구성 보고 필요 |
| — | **영역별 상대적 중요도** (100점 배분) | 영역 가중치·개발 우선순위 산출 |
| — | **2차 이후 설문**에 이전 차수 중앙값·사분위 범위·CVR 자동 표시 | 델파이 기법의 핵심 절차(통제된 피드백) |

## 2. 연구자 추가 제안 문항 `[신규]` (6개)

설문지에서 주황색 `[신규]`로 구분되며, `survey/survey-config.tex` 의
`\ShowProposedItemsfalse` 로 한 번에 숨길 수 있습니다. 개별 삭제는 `items.tex` 에서 해당 줄을 지우면 됩니다.

| 번호 | 구성요소 | 근거 |
|---|---|---|
| 2.4.1 | 예법(禮法) 수련 | "무도적 가치"를 영역 정의에 명시했으나 이를 다루는 문항이 없음 |
| 3.2.3 | 타돌부(物打) 판정 | 유효격자 요건 중 "죽도의 타돌부로 타격"이 정격 판정 문항에 빠져 있음 |
| 3.2.4 | 잔심(殘心) 판정 | 유효격자의 필수 요건이며 검도 교육에서 강조되는 요소 |
| 4.3.2 | 지도자 모니터링 및 원격 코칭 | LMS 가 수련자 개인용으로만 구성됨. 도장·학교 현장 활용성 |
| 4.4.1 | 안전 경계 및 충돌 방지 | 죽도를 휘두르는 VR 훈련 특성상 필수 안전 요소 |
| 4.4.2 | 사이버멀미 및 피로 관리 | VR 콘텐츠 사용성 연구에서 핵심 변인 |

## 3. 연구자 확인이 필요한 사항 (원문은 수정하지 않음)

1. **3.1.1 심검체(心劍體)** — 검도에서 일반적으로 쓰는 용어는 **기검체일치(氣劍體一致)** 입니다.
   원본은 心을 "시선"으로 정의했는데, 氣(기세·기합)는 이미 2.3.1 기합 음성 인지로 측정하므로
   "기합(氣)-죽도(劍)-발구름(體)" 동기화로 정의하는 편이 용어와 측정이 일치합니다.
   4.3.1, 5.4.1 의 "심검체 일치도"도 함께 바뀝니다.
2. **2.2.1 일간의 거리(一間之間)** — 표준 용어는 **일족일도(一足一刀)의 간합**입니다. 의도한 용어인지 확인하세요.
3. **2.1.2 응용/격권 수련** — "격권"이 오타인지(예: 호격 연습, 응용 기술) 확인이 필요합니다.
4. **3.2.1 칼날 각도 45도 이내** — 수치 기준의 출처(규정·선행연구)를 논문에 제시해야 합니다.
5. **5.1.1 단/급 승단 체계** — 대한검도회 공식 단·급과 혼동될 수 있어 "가상 등급/칭호"로 표현하는 편이 안전합니다.
6. **중복 가능성** — 2.2.2 대적 AI 엔진 ↔ 5.2.1 동적 난이도 조절, 3.3.2 수련 데이터 시각화 ↔ 4.3.1 수련 리포트.
   전문가가 차이를 구분할 수 있도록 설명을 더 분명히 하거나 통합을 검토하세요.
7. **문항이 1개인 중분류** — 2.3, 3.1, 4.1, 4.2, 5.3. 1차 조사의 개방형 의견으로 보강할 수 있습니다.

## 4. 조사 진행 절차

```bash
# 1차: 설문지 배포 (survey/delphi-survey.pdf) 후 응답 입력 양식 생성
python analysis/delphi_analysis.py template -o data/round1.csv
# 응답 입력 후 분석 → 논문 표 + 2차 설문지용 통계 생성
python analysis/delphi_analysis.py analyze data/round1.csv --round 1 --survey-stats
# 2차: survey-config.tex 의 \DelphiRound 를 2로 바꾸고, 채택되지 않은 문항 수정 후 푸시
python analysis/delphi_analysis.py analyze data/round2.csv --round 2 --prev data/round1.csv --survey-stats
```

채택 기준: CVR ≥ 최소값(Lawshe, 1975; N=12 → .56), 합의도 ≥ .75, 수렴도 ≤ .50, CV ≤ .50.
`analysis/example_round1.csv` 는 **동작 확인용 가상 데이터**이며 연구 결과가 아닙니다.
